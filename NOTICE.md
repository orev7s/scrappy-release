## Derived material

- `docs/wire-format.md` describes scrcpy's stream framing, read from its source at the commit
  above. The description is Scrappy's own, the format is scrcpy's.
- `schema/scrcpy-options.json` is generated by `tools/gen_schema.py` from scrcpy's option table.
  `source_commit` in the file records which upstream commit it came from. Only the option
  descriptions, flags and defaults are carried over; the settings UI and the argument builder are
  Scrappy's.
- The FFmpeg libraries are published as a release asset, not as source. They are a build of
  FFmpeg 4.4, which the Windows app matches its bindings to, and the app downloads them on first
  run. FFmpeg is a separate project with its own licence; see ffmpeg.org.
